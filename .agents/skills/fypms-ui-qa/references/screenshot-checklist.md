# Screenshot checklist (375, 768, 1280 px)
- [ ] No overlapping elements; nothing clipped at card, sidebar or viewport edges
- [ ] No horizontal page scroll; wide tables scroll inside their own container
- [ ] Current/active/selected state shows exactly one indicator
- [ ] Tabs, filters and toolbars sit above the content they control
- [ ] Sidebar footer, top bar and bell/avatar fully visible (dev badge not covering anything)
- [ ] Text readable (AA contrast), no unintended truncation, badges on one line
- [ ] Touch targets >= 44 px on mobile; focus ring visible
- [ ] Loading, empty and error states look intentional
- [ ] Data shown matches the fixtures (names, emails, contacts, group numbers)
